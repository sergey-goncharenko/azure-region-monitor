# Roadmap Overview

This roadmap defines the staged delivery of the Azure Regional Feature Availability Monitor:

- PoC: Prove read-only synthetic testing works across Azure regions. Completed.
- MVP: Public dashboard + diffs + static JSON APIs. In progress, with dashboard, history, and focused workflows running.
- v1: Alerts + API hardening
- v2: Advanced analytics + timelines
- v3: Full SaaS integration + SDKs

Current implemented modalities: AKS extension catalog, AKS Kubernetes versions, Azure Functions Flex Consumption locations and Linux runtimes, Azure AI model catalog listings, Container Apps provider metadata, and VM SKU listings.
