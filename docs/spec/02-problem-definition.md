# Problem Definition

Azure services roll out features region-by-region with no public telemetry. Documentation often lags reality by days or weeks.

This creates problems for:
- SaaS companies expanding to new regions
- Teams relying on specific AKS extensions
- Companies needing to know when Azure OpenAI models become available
- Engineers diagnosing regional regressions

There is no public, real-time, machine-readable source of truth.

This project solves that.
